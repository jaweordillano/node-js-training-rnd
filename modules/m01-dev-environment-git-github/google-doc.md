## Differences from the HTML page

- The Windows, macOS and Linux tabs are flattened into one sub-section per operating system.
- Checkboxes are plain "☐" characters, and the collapsible answers and troubleshooting entries are
  shown open.
- The three-places diagram is a one-line text diagram.
- Code blocks are plain text, not monospaced. Format them in Docs if you want them to stand out.

## Keeping it in sync

When `index.html` and `index.md` change, update this Doc in the same change. Edit the existing Doc
so the link stays the same. Do not create a new one.
